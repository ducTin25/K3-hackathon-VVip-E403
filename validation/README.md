# User validation

Tối thiểu năm người ngoài nhóm, trong đó có ít nhất hai willing user đã khai từ CP1.

Mỗi phiên:

1. Giao một task thật và im lặng quan sát.
2. Hỏi điều khó hiểu/khó chịu nhất.
3. Hỏi họ có tin kết quả không và vì sao.
4. Hỏi họ có dùng thật không và vì sao.
5. Ghi quote nguyên văn, tên/vai và mức nghiêm trọng.

Sau validation, cập nhật `feedback-log.csv` và `spec.md` §9 Changelog.
